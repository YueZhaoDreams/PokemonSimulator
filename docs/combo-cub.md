# Combo Cub

Public name for this fan-made card-game simulator. Domain **combocub.com** was registered 2026-08-29.

| | |
|---|---|
| Product | Combo Cub |
| Chinese | 招式小熊 |
| Domain | [combocub.com](https://combocub.com) |
| Character | a cub that tests lines, not a coach that invents every play |
| Catchphrase | Will it win? |
| Role | strategist (策略师 / 小军师): you find the combo; it runs the line |

The engine still supports custom rules and any scanned deck. Pokémon Family Cup is one format, not the brand. The domain and app title should stay **Combo Cub** — no Pokémon / Poke / official Trainer-card names.

Do not fold extra names into the storefront (Junshi, Secondie, Will It Win). Those can stay as how the cub talks. The Lab remains the cub’s workbench, not a second product name.

This is a fan-made simulator. It is not affiliated with Nintendo, Game Freak, or The Pokémon Company.
